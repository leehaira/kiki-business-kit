# Sample design README

> Ví dụ cho `docs/design/phase-n/README.md`. Dùng để mô tả screenshots, Figma exports, PDFs, hoặc visual evidence cho UI/static/landing work.

## Source

| Field | Value |
|-------|-------|
| Project | project-name |
| Design source | Figma / screenshot / PDF / client reference |
| Export date | YYYY-MM-DD |
| Related plan | `docs/plan/EPIC-xxx-slug.md` (optional) |
| Related status | `docs/PROJECT-STATUS.md` |

## Files

| File | Purpose | Notes |
|------|---------|-------|
| `overview.png` | Full section overview | Desktop 1440 |
| `mobile.png` | Mobile reference | 390 width |
| `style.png` | Typography/color/spacing reference | Tokenize when possible |
