# Agent Team Template — slide intro

Deck giới thiệu template. Mở trình chiếu bằng cách mở `index.html` trong trình duyệt.

| File | Vai trò |
|------|---------|
| **`slides-content.md`** | Nguồn nội dung từng slide — **sửa đây trước** khi đổi wording |
| **`index.html`** | Deck chiếu (plain HTML, không cần build) |
| **`agent-team-template-intro-notes.md`** | Speaker notes (không chiếu) |
| `assets/` | Ảnh / icon nếu bổ sung sau |

```bash
open docs/guides/agent-team-template-intro/index.html
```
